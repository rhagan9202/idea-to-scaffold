# Stage 3 — Requirements

Using the approved vision and features:

1. For each **Must** and **Should** feature, derive functional requirements `FR-nnn`. One testable behaviour each. Every FR gets `Feature:`, `Priority:` and Given/When/Then acceptance criteria, including at least one failure or edge case.
2. Add non-functional requirements `NFR-nnn` in a table covering performance, security, privacy, accessibility, reliability and anything else that matters here. Each needs a measurable target.
3. Add a **Data & privacy** section: what data is stored, retention, PII.
4. Update the `Requirements:` lines in `02-features.md` to list the new FR IDs, and re-emit that file too.
5. Write `planning/03-requirements.md`. Flag any requirement you think is risky or vague. Revise until I approve.
