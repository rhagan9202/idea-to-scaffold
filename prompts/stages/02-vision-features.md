# Stage 2 — Vision and features

Using `00-idea.md`:

1. Ask any questions you still need about users, goals and scope.
2. Write `planning/01-vision.md`: Problem, Target users (persona table), Goals `G-n` (measurable), Non-goals, Success metrics (table linked to goals), Constraints & assumptions.
3. Write `planning/02-features.md`: a summary table (ID, Feature, MoSCoW priority, Supports, Milestone) followed by one section per feature with a user story, description, edge cases, and placeholder `Requirements:` and `Screens:` lines.
4. Keep the first release small: at most ~6 **Must** features. Move the rest to Should/Could/Won't and say why.
5. Ask me to review. Revise until I say "approve" for both files.
