# Stage 6 — Project plan

Using everything approved so far:

1. Define milestones. **M1 is always a walking skeleton**: the app builds, tests and lint run, CI is green, and one trivial path works end to end.
2. Break each milestone into tasks `T-n.m`. Each task must:
   - be small enough for one coding-agent session (about half a day of human work or less)
   - list `Satisfies:` (FR/NFR IDs) and `Depends on:` (task IDs or —)
   - have a **Do** line and a **Done when** line that a test or a reviewer can check
   - end with a `- [ ] Done` checkbox
3. Order tasks so each milestone ends with something demoable.
4. Add a Risks table (risk, likelihood, impact, mitigation).
5. Check traceability and report: any Must FR not covered by a task, any task that satisfies nothing.
6. Write `planning/06-project-plan.md`. Revise until I approve.
